# FlowDesk Studio

FlowDesk Studio 是一个完全运行在浏览器中的企业级低代码流程编排与审批监控演示平台。项目使用 React、TypeScript、Vite、Zustand 和 React Flow，所有数据均为本地 mock，不需要后端、登录或外部 API。

## 启动

需要 Node.js 20+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。建议使用 1440px 或更宽的现代桌面浏览器。

## 测试

首次运行先安装 Chromium：

```bash
npx playwright install chromium
npm test
```

Playwright 会自动启动 Vite（端口 4173），串行验证 Dashboard、编辑器审批配置、双区域校验、条件修复、动态表单预览、发布联动、异常实例详情、版本比较和历史恢复，以及受控子流程的插入、升级检查、接入点缺口拦截和归档源引用。测试失败时会保留截图和 trace。

## 浏览器验证路径

1. Dashboard 点击“差旅费用审批”进入编辑器。
2. 选择“直属主管审批”，切换审批人来源并保存草稿。
3. 运行校验，观察 Condition 节点红色错误态和底部问题面板。
4. 选择“金额判断”，配置申请金额大于 5000，再次校验。
5. 打开预览，输入金额 12000，观察模拟分支切换。
6. 返回并发布；在 Dashboard 和 Workflows 检查状态及版本。
7. 进入运行监控，筛选异常并打开实例，查看时间线及高亮节点。
8. 从编辑器进入版本历史，选择两个版本比较，再恢复旧版本为草稿。

## 受控子流程引用

采购和人事共用同一套“员工入职审批”，复制不再生成各改各的节点，而是保留受控引用：

- **插入即锁版本**：编辑器节点库点击“受控子流程”，只能选择已发布且最新版带结束节点的流程；插入时锁定当时最新发布版本（如员工入职流程 v2）。
- **新版只提示升级**：源流程发布 v3 后，父流程不自动改动；流程列表、编辑器升级条、节点配置面板和版本历史都显示“锁定 v2 · 最新 v3 · 可升级”。
- **升级前检查接入点**：确认引用节点在父流程上仍有上下游连线、目标版本含开始与结束节点；通过后才出现“确认升级”。缺少下游连线（年度预算调整）或目标版本缺结束节点（法务审查引用合规会签 v2）时留在“待处理”并逐项列出缺口。
- **存量实例不受影响**：升级仅改变后续走向，引用上记录的运行实例继续按插入版本运行。
- **归档只挡新插入**：供应商准入归档后，用印申请中的既有引用照常显示与运行，但插入选择器不再列出该源。
- **复制相互独立**：复制父流程时引用一并复制，锁定版本与升级状态各自独立，互不影响。

验证入口：流程列表“受控子流程 / 待升级”列；打开“采购合同审批”编辑器底部“受控子流程升级”条；“年度预算调整”查看待处理缺口；“用印申请”查看归档源引用；版本历史页底部“受控子流程引用”。

## 项目结构

- `mock-data/`：13 个流程（含共享入职审批子流程、待升级与归档引用案例）、80 个实例、8 个用户、6 个角色、5 个业务域及边界案例。
- `src/components/`：布局、公共状态组件和 React Flow 画布。
- `src/pages/`：Dashboard、流程列表、编辑器、表单预览、运行监控、版本历史。
- `src/store/`：Zustand 全局状态、校验、发布、复制、归档、恢复及受控子流程插入/检查/升级逻辑。
- `src/lib/`：受控引用状态汇总、升级前接入点检查、可插入源筛选。
- `src/types/`：核心业务数据 TypeScript 类型。
- `tests/`：关键产品链路 Playwright 测试。

## Mock 边界案例

数据集中包含空流程、孤立审批节点、缺少结束节点、未配置条件分支、审批人为空、表单必填校验、超长流程名称、超长说明展示能力、无异常实例，以及由搜索筛选产生的空结果状态。
